# 🦁 SoundSafari - Pre-K Audio & Reading Academy

**SoundSafari** is an interactive, sound-first web application designed to prepare Pre-Kindergarten children (ages 3–5) for school. It teaches alphabet phonics, CVC word spelling, sentence building, rhyming matching, multi-letter blends, and voice pronunciation practice.

---

## 🌟 Key Features

- **🔤 Alphabet Phonics Jungle**: A–Z letter cards with phonetic breakdowns, example words, and an interactive Phonics Song.
- **🎙️ Say & Play (Voice Studio)**: Powered by the Web Speech API (`SpeechRecognition`) with an animated microphone and phonetic matching feedback for kid's pronunciation practice.
- **🧁 Word Bakery**: 40+ CVC words with category filters (Animals, Home, Nature, Vehicles, Food).
- **🦁 Sentence Safari**: 100 interactive 3–6 word reading sentences with real-time word read-along highlighting and sentence randomizer.
- **🧩 Digraphs & Blends Lab**: 25 blends (CH, SH, TH, WH, BL, CL, FL, ST, TR, DR, etc.) with spoken anchor prompts.
- **⭐ Gamification**: Unlockable sticker rewards album and parental speech rate controls.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation & Local Run

```bash
# Clone repository
git clone https://github.com/<your-username>/soundsafari.git
cd soundsafari

# Install dependencies
npm install

# Run development server
npm run dev
```

### Production Build

```bash
npm run build
```
